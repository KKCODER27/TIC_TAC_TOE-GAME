# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe web game** developed using **HTML, CSS, and JavaScript**.  
This project demonstrates front-end development concepts such as DOM manipulation, event handling, and game logic implementation.

---

## 📌 Project Overview

This project recreates the classic Tic-Tac-Toe game played between two players on a 3×3 grid. Players take turns marking **X** and **O**, and the game automatically detects the winner or draw condition.

The goal of this project was to strengthen JavaScript fundamentals while designing a clean and user-friendly interface.



## 🚀 Features

- ✅ Two-player gameplay (X vs O)
- ✅ Automatic winner detection
- ✅ Draw condition handling
- ✅ Reset Game functionality
- ✅ New Game option
- ✅ Interactive button-based game board
- ✅ Simple and clean UI design


## 🛠️ Technologies Used

- HTML5 — Structure
- CSS3 — Styling & Layout
- JavaScript — Game Logic & DOM Manipulation
